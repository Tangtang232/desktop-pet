这一版主要是让它更靠得住：存档不会丢，一起养不能被冒认，服务器也更省。装了 0.1.0 的直接运行新的安装包，装在原来的位置上，狗和一起养都还在。

**下载哪个**

- `DesktopPet-Setup-0.2.0.exe`：大多数人选这个，双击就装好并自动打开，不用管理员权限
- `DesktopPet-0.2.0-win-x64.zip`：不想安装时用，解压到一个固定的文件夹，双击里面的 `DesktopPet.exe`（用压缩包的：先从托盘退出旧的，再解压覆盖原来的文件夹）
- 最下面的 Source code 是源码，不用下

没有数字签名，Windows 会弹"Windows 已保护你的电脑"：点"更多信息"→"仍要运行"。

**存档不会丢了**

- 0.1.0 开机时电脑很忙的话，有可能把存档盖成一只新狗（狗变回"第一天来到这里"）。这一版读到存档之前不存档
- 存档每小时留一份备份；断电把存档写坏了，用备份接着养，坏的那份留在存档目录里
- 以后的版本如果改了存档格式，再装回 0.2.0 也不会把新存档覆盖掉（会提示装回新版本）

**一起养更安全**

- 换了电脑认回自己：要你原来那台电脑点「是我」，或者组里其他人都同意。以前一个人同意就行，只有你一个人的组甚至凭邀请码就能冒充你
- 这台电脑的登录在服务器那边失效了，会自己认回原来的身份，不会悄悄掉出组
- 认领别人被拒以后，能正常点"第一次来，加入"
- 名字里不能再塞看不见的字符冒充别人
- 服务器加了容量保护，也不再因为每次心跳整套刷新（4 个人时以前每 30 秒约 20 次）

**两个人才算一起养**

- 点「邀请朋友一起养」只是发出邀请：拿到邀请码，狗还是你自己的。朋友输入邀请码、你点同意，才开始一起养
- 邀请不过期，不想邀请了点「不邀请了」。一起养过、后来只剩你的，回到"等朋友加入"，组不散

**别的**

- 动画出错、显卡重置时狗不会冻住或消失，会自己恢复
- 拖文件到狗身上不会再把它弄没
- "看看它"窗口开着 10 分钟没理，会先停一停，点一下接着看
- 第一次打开会提示右键能干什么
- 托盘 →「关于」→「复制诊断信息」：出问题时粘贴发给维护的人（没有邀请码、纸条和名字）
