第一个版本。一只住在 Windows 桌面上的小比格，可以拉朋友一起养。

**下载哪个**

- `DesktopPet-Setup-0.1.0.exe`：大多数人选这个，双击就装好并自动打开，不用管理员权限
- `DesktopPet-0.1.0-win-x64.zip`：不想安装时用，解压到一个固定的文件夹，双击里面的 `DesktopPet.exe`
- 最下面的 Source code 是源码，不用下

没有数字签名，Windows 会弹"Windows 已保护你的电脑"：点"更多信息"→"仍要运行"。

**一起养**

装好后右键点狗（或者任务栏右下角托盘里"桌面比格"的图标）→「一起养…」。一个人点「邀请朋友一起养」，把邀请码发给朋友；朋友点「输入邀请码」，组里的人同意后就进来了。一个组最多 4 个人。

**这一版有什么**

- 自己溜达、闻来闻去、犯困了趴下睡；饿了去碗边等饭，你走开它就睡，你回来它跑过来迎你
- 摸它、拎起来、喂它；左右两块屏幕之间会自己走过去
- 一起养：自己去朋友桌面串门、叫它回来、看看它在朋友那儿干嘛、隔空喂一碗、让它叼纸条（纸条加密）
- 每只狗有自己的脾气，会慢慢变亲人或变冷淡、变胖变瘦，日记里都记着
- 待在桌面层，不抢焦点、不占快捷键；被窗口盖住时停止绘制，很省 CPU
- 有新版本时托盘菜单里会提醒（不会自己下载安装）
