修 0.2.0 的一个问题：点了「邀请朋友一起养」、朋友还没加入的时候写纸条，会提示"还没有人和你一起养"，纸条发不出去。现在这种时候和没一起养一样，狗叼着纸条出去转一圈再回来。已经和朋友一起养的不受影响。

装了 0.2.0 或 0.1.0 的，直接运行新的安装包，装在原来的位置上，狗和一起养都还在。

**下载哪个**

- `DesktopPet-Setup-0.2.1.exe`：大多数人选这个，双击就装好并自动打开，不用管理员权限
- `DesktopPet-0.2.1-win-x64.zip`：不想安装时用，解压到一个固定的文件夹，双击里面的 `DesktopPet.exe`（用压缩包的：先从托盘退出旧的，再解压覆盖原来的文件夹）
- 最下面的 Source code 是源码，不用下

没有数字签名，Windows 会弹"Windows 已保护你的电脑"：点"更多信息"→"仍要运行"。
