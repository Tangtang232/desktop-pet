> 2026-11-26。这一轮只有一个目的：**让现有的动作看起来更自然**。先不加新玩法。
> 你上一轮做的"趴着站起来"（`src/renderer/rise.js`，同一个轮廓连续变形）我们验收过了，方向是对的。这一轮把同样的做法推到其他换姿势的动作上，顺手把起身剩下的两处毛病修掉。

## 0. 现在的问题出在哪

| 截图 | 是什么 | 重影在哪几帧 |
|---|---|---|
| `tr-sit-*` | 站 → 坐（中间经过半蹲） | 1–2 后腿重影；**6 整个身体叠成两层** |

## 1. 要做的动作（按优先级）

时长是参考值，看着自然可以调。"真狗怎么做"是动作的要点，不用逐条照抄，但先后顺序要对。

### P0（这些是每天都会看到的，先做）

**1. 趴 → 睡、睡 → 趴（最难看的一组）**
- 趴 → 睡，1.8–2.4 秒，要慢，要有犯困的感觉：先把下巴搁到前爪上，眼睛半闭，停一小会儿；然后身体往一侧倒，弯成弧形，头往回转、朝尾巴埋下去，尾巴从后面绕到身前。
- 睡 → 趴，约 1.2 秒：先抬头、睁眼（可以眨两下），身体从弧形展开回趴姿，尾巴摆回身后。
- 难点在头：从侧脸变成埋头，朝向变了，光靠同一轮廓变形做不出来。**不能出现两个头半透明地叠着**。可以考虑的办法：补一张"下巴搁在前爪上"的趴姿（头还是侧脸，能接着用脸部套件，平时也能当一个闲着时的姿势）；补一两张"头转到一半"的图；或者让头在被前爪、身体挡住的那一瞬间直接换图。用哪种你来定。如果要出新图，按第 3 节的规矩来。

**2. 站 → 坐、坐 → 站**
- 站 → 坐，约 0.7 秒：前爪不动；屁股往后下方沉，后腿从膝盖处折起来、收到身体下面；最后一下稍快，像"一屁股坐下"；背从水平变成前高后低；尾巴落到地上。
- 坐 → 站，约 0.6 秒：头和胸先往前探一点，把重心移过去；后腿蹬直、屁股抬起来；后爪可以往前补一小步；尾巴抬起来。
- 现在 `rise.js` 只认趴、趴到一半、半蹲、站这四套图。坐姿也要加进去。

**3. 坐 → 趴、趴 → 坐**
- 坐 → 趴，约 0.9 秒：屁股不动；两只前爪**一前一后**往前走出去（各迈一步，不是两只一起滑出去）；胸口和手肘慢慢落到地上；头先往前低，再抬到趴姿的高度。
- 趴 → 坐，约 0.7 秒：前爪一前一后往回收、撑起来，胸口抬高；屁股不动。

**4. 站 → 趴（一口气趴下）**
- 现在要先坐下、停一下、再趴，前后 2 秒多，显得磨蹭。改成一口气做完，1.2–1.4 秒，中间不在坐姿停。
- 可以把起身倒着放（后半身先沉下去，前爪再往前走出去），也可以先低前身、后半身再落下。哪种自然用哪种。
- 起身和趴下都要能中途反悔：已经有 `updateRise` 倒放的逻辑，沿用就行。

### P1

**5. 起身剩下的两处重影**（你做的对比页 `beagle-rise` 里能看到）
- 第 15–19 帧：近侧前腿从胸口"渗"出来那一段是半透明的。
- 第 24–28 帧：屁股和后腿发糊，尾巴能看到淡淡的两条，这一处最明显。
- 两张图在同一张网格上混合时，内部的斑纹、腿、尾巴对不上，就会糊。可以缩短混合的区间，或者按部位分开决定什么时候换图。

**6. 转身**
- 规矩不变：**不出现正脸**。之前试过斜 45° 正脸的转身图，看着很怪，已经不用了（见 `asset-spec.md` 第 3.3 节）。
- 现在是横向压扁再翻面，最窄的时候像一张纸片。可以让头先转过去（像回头看），身体再跟着翻，落下时爪子换一下位置；或者翻面时配一个低头、小跳之类的动作，把最窄的那一下藏起来。0.45 秒以内。

- 抖毛（落地后）、低头嗅、吃饭、被拎起来挣扎、落地。

## 2. 验收标准（每个动作都要满足）

1. **任何一帧都不能出现重影**：两个头、两条尾巴、两层身体半透明地叠在一起，都不行。
2. **爪子不打滑**：承重的那只爪子在屏幕上的位置不能漂。照着"起身时前爪踩稳再迈步"的写法，给每个动作加一条冒烟测试。
3. **一口气做完**：动作本身没要求停的地方，中间不能顿一下。
4. **能被打断**：动作做到一半被拎起来、或者它改主意了，要顺着倒回去或加快做完，不能跳帧。
5. 做动作时，表情、眨眼、耳朵、摇尾巴照常；身体阴影和爪子阴影跟着动。
6. 外轮廓连续，不能出现缺口、撕开，或者被拉成怪形状。
7. 动作没做完不能开始走路。

## 3. 限制

- **性能**：狗静止时（站、坐、趴、睡）CPU 不能比现在高。做动作时可以跑 30 帧，做完马上降下来。内存现在是 385–408 MB，做完不要超过 420 MB。改之前、改之后各跑一次 `powershell -File tools/bench.ps1`，把两次结果都附上。
- **通用**：把 `rise.js` 整理成通用的"过渡动作"模块，每个动作只写自己的参数（关键姿势、时间点、每只爪子什么时候抬、什么时候落），不要每个动作各抄一份。
- **以后要换图**：以后还有 7 个成长阶段，每个阶段一套图。动作参数不要写死成幼犬的像素数（比如现在 `RISE_STEPS` 里的抬爪高度 29、38、49），按身体尺寸的比例算。
- **别动的地方**：`src/main/desktop-layer.js`、窗口层级、纸条、喂食、存档的逻辑。
- **新素材**：格式按 `docs/art/asset-spec.md` 第 2、3 节来（8 个图层、同一比例尺、配 `rig.json`），先登记进 `asset-spec.md` 第 3.3 节的表格。原图放在 `assets/beagle/hd-library/`，这个目录不进 git。放好后跑 `python tools/build_hd.py` 重新打包，`rig-data.js` 每加一个姿势别超过 0.3 MB。
- **不要提交 git**。改完跑 `npm test` 和 `npm run smoke`，必须全部通过（现在单元测试 15 项，冒烟测试 40 项）。

- `update` 里要掉头或正在转身时，把 `T.sniff`、`T.bow`、`X.scent` 清零。
- 加了一条冒烟检查"闻地面时掉头先抬头"。

所以 `turn.js` 可以照旧假设转身时是站直抬头的姿势。如果你想让它低着头也能转，那是另一回事，这轮不用做。
